# HyperDev Phase 2 — Private App Factory

## Goal
Build a private factory that repeatedly produces researched, monetized apps quickly.

## Pillars
1. Research → Validate → Decide
2. Spec → Scaffold → Ship
3. Monetize-first plumbing
4. Knowledge feedback loop

## Non-negotiables
- HyperDev is not sold publicly (factory stays private).
- Only generated apps are published.
- Every shipped app must have a monetization plan and tracking.

## Outputs
- Archetypes (templates)
- Agents (research/spec/scaffold/deploy/growth)
- Playbooks (repeatable launch + deploy)
- Knowledge base (what works, what fails)
